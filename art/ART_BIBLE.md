# 模型美化规范（工业产品方向）

## 优先级与风格

本项目的首要目标是模型美化：可读的轮廓、可信的材质、协调的色彩与经得起近看的细节。其次才是文件体积。不能用更小的文件作为美术通过条件。

默认方向是数字孪生设备/工业产品：保留真实比例、功能结构、设备标识和安全色；克制的高光、清晰的材质分工、稳定的视觉重心。没有用户参考时先采用此方向并记录假设，不要求用户逐项批准常规可逆操作。角色不是一个固定风格包，必须结合输入模型建立本次方案。

## 美术指导应先交付的方案

在 `art/<asset>-v1.json` 中写可执行参数，在同名 `.md` 中记录：

- 模型用途、目标观看距离、原模型问题（附截图路径）、不应改变的设备语义。
- 一句话视觉方向，主材质/次材质/强调色的分工，以及参考图路径（如有）。
- 每条修改对应的精确节点名与材质名；不能仅根据名字猜“这是金属”。
- 修改理由、预期视觉改善、可能受损的轮廓/贴图/透明部分和需要保护的节点。
- 本次预算和停止条件。没有预算不编造 FPS/显存目标。

`industrial.json` 是保守起点，materials 为空，不会自动把全模型染蓝或改成金属。`demo.json` 只对应示例模型，不能直接套到用户资产。

## 五项美术标准

1. **轮廓和比例**：六向轮廓完整；倒角宽度从近看可识别、远看不扭曲的范围开始；薄壁、螺纹、接口、铭牌与管线不得被吞掉。不能靠改变相机掩盖缺陷。
2. **材质可信度**：先区分喷漆金属、裸金属、橡胶、塑料、玻璃等，再决定 metallic/roughness。金属并非越亮越好；塑料通常不应设为 metallic=1。保留原贴图/法线/UV；无足够依据不删除或替换它们。
3. **色彩和视觉层级**：主体、连接件、功能部位可辨。原安全色、编号与品牌色保留；强调色服务于结构而不是平均撒到所有部件。主色/辅色比例依资产选择，不把固定百分比当成普遍定律。
4. **表面与工艺**：硬表面的小倒角服务真实边缘高光；大平面保持平直，不出现波纹和莫名凹陷。法线平滑不能把机械棱角抹成蜡。污渍、磨损应有位置和成因，不能随意全屏加噪声。
5. **灯光与交付一致**：中性三点棚灯用于暴露表面问题，六向加 hero 对比保持完全相同的相机/灯光/曝光/AgX/分辨率。模型本身的几何和 PBR 改动须落入 GLB。地面、棚灯、相机和 AgX 属于 `.blend` 展示，不会自动变成 Three.js 环境效果。

## 评审与迭代

宿主 AI 必须实际查看 `before-*.png` 与 `after-*.png`，以相同视角成对评价。每项 1–5 分（1 严重问题、3 可接受但明显可改进、5 达到本次方案），评分是审阅判断，不是程序测量。填写本次 `review.json`：

```json
{
  "status": "changes-requested",
  "reviewer": "Claude Code / 实际审阅者",
  "criteria": {"silhouette": 4, "materials": 3, "color": 4, "surface": 2, "delivery": 4},
  "evidence": ["before-hero.png", "after-hero.png"],
  "issues": ["Body 顶部有平滑波纹，见 after-hero.png"],
  "nextIteration": ["减小 Body 倒角，保留平面法线"]
}
```

只有看过全部要求视角、无未处理的重大问题、结构/格式检查通过且模型修改确实达到方案，才可以写 `approved`；无法查看图片时为 `not-assessed`，缺少证据不编造评分。`report.json.visualReview` 由 CLI 始终写 `pending`，独立的 `review.json` 是后续审阅记录；二者不要混淆。

每次回到原始模型，以新版本方案重跑，禁止在上次结果上反复叠加倒角。默认最多三轮；未通过要交付问题清单和最佳可用候选，不能声称彻底修复。明确记录每轮输出目录、发现、修正和最终推荐；不要按最小文件体积选美术结果。

## 当前执行能力边界

Material Maker 分支支持六种官方预设，通过 `materials[].preset` 导出 PBR 贴图并由 Blender 应用。详见 `docs/material-maker.md`。缺少 UV 时可显式生成基础 Smart UV；这不等同于美术级手工 UV 重展。材质预设是否合适仍须逐部件决策、查看前后截图。

已有自动执行：静态封闭网格的小倒角、角度锐边与加权法线、按材质/节点选择的 PBR 颜色/粗糙度/金属度调整、Cycles 棚拍、导出重导入对比和结构检查。

复杂 UV 重展与手工布局、贴图烘焙、重拓扑、缺失零件重建、按模型结构烘焙磨损与摄影纹理生成不是现有参数可执行的操作。若资产需要这些，技术美术应编写并测试针对该模型的 Blender Python 扩展，再进入同一渲染验收流程；不能在文字方案里写完就算实现。
